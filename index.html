关于站主

缘起

编写这个网站的契机大概是闫宏飞老师“数据结构与算法 (B)”课程群里的一条消息：

“推荐大家申请个 github 账号，开个自己的主页。我的如下”

闫老师发了张截图，展示了他的主页：一串课程链接。它如此简单，但它是独属于闫老师的。闫老师当然不乏独属于他自己的作品，但通过部署个人网站，我也可以展示自己那一点点的独创，这实在是一件很浪漫的事。

于是我打开了自己上学期写的一个简陋的.hmtl文件：“Hello World”、学院官网链接、“吉他手工小成”图片和下载链接、和一些莫名其妙的变色按钮。仍记得北大的超长寒假刚开始时，我还励志学好 html。但那简陋的文件刚放假时是什么样，开学了就还是什么样。（待续）
