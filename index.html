缘起

编写这个网站的契机大概是闫鸿飞老师“数据结构与算法 (B)”课程群里的一条消息：

“推荐大家申请个 github 账号，开个自己的主页。我的如下”

闫老师发了张截图，展示了他的主页：一串课程链接。尽管它如此简单，但它是独属于闫老师的，是闫老师的“个人作品”。这实在是一件很浪漫的事。
